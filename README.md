# 🕉️ Gita Gyan (શ્રીમદ્ ભગવદ્ ગીતા)

> એક દિવ્ય અને આધુનિક પ્લેટફોર્મ જ્યાં ભગવાન શ્રીકૃષ્ણના અમૃતમય ઉપદેશો, તમામ ૧૮ અધ્યાયો અને ૭૦૦ શ્લોકોનું સરળ ગુજરાતી અને હિન્દીમાં સચોટ જ્ઞાન ઉપલબ્ધ છે.

🌐 **લાઈવ વેબસાઇટ:** [https://gita-gyan-m.vercel.app](https://gita-gyan-m.vercel.app)

---

## ✨ મુખ્ય વિશેષતાઓ (Features)
- 📖 **૧૮ અધ્યાય અને ૭૦૦ શ્લોક:** સંસ્કૃત શ્લોક, અન્વયાર્થ અને સરળ અનુવાદ.
- 🤖 **Gita AI Assistant:** ગીતાના ઉપદેશો પર આધારિત પવિત્ર માર્ગદર્શન.
- 🎯 **ગીતા ક્વિઝ (Quiz):** અધ્યાયવાર પ્રશ્નોત્તરી અને પરીક્ષા.
- 🔖 **મનપસંદ શ્લોક (Bookmarks):** શ્લોકો સાચવવાની અને વાંચવાની સુવિધા.
- 🔔 **દૈનિક નોટિફિકેશન:** દરરોજ પવિત્ર શ્લોકનું માર્ગદર્શન.

---

## 🛠️ ટેકનોલોજી (Tech Stack)
- **Frontend:** React, Vite, Lucide Icons
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Hosting:** Vercel (Frontend), Render (Backend)
- **Email Service:** Brevo
